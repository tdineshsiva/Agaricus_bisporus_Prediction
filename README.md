# Agaricus bisporus Prediction using Machine Learning

This project focuses on **predicting characteristics of Agaricus bisporus (white button mushroom)** using machine learning techniques. The model analyzes dataset features and predicts whether the mushroom is **safe / edible or not**, based on multiple biological and environmental parameters.

This repository contains:
- Preprocessed dataset
- Jupyter Notebook (`.ipynb`) with full implementation
- Model training, evaluation, and prediction pipeline

---

## 🚀 Project Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA) with visualizations
- Feature selection and correlation study
- Machine learning classification model
- Accuracy, confusion matrix & precision report
- Final user prediction cell

## 🧾 Dataset Information
The dataset contains biological and physical descriptions of mushrooms.  
Each entry includes features such as:
- Cap shape, cap surface, cap color
- Gill attachment, gill size, gill color
- Odor, stem size, habitat, etc.

The target label indicates whether the mushroom is **safe / edible** or **unsafe / non-edible**.
